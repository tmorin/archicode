## Findings

- #123 was real and larger than written: the typed values were lost before the dialog opened (`guardedLayerWrite` redraws twice), not only on Cancel. The issue had been written from a harness without a DOM; reproducing in the built-in browser first (plan T2) found the real cause.
- #82's measured defect (top bar 344 px, Settings past the window) was already gone after the band rework; the run found four other places past the window at 360 px that no test saw because the node harness has no layout engine.
- The composition of `replaces` went to the kernel rather than the hosts: written once, both tools agree by construction (shared cases R01 to R11).
- Re-embedding the kernel can add a wasm-generated class that `NativeReflectionConfigTest` wants in `reflect-config.json` (W-7); W-8 did not need it.

## Lessons Learnt

- An edit of an element in a layered workspace runs on a clone of the resolved node, not on the file's node: a form that addresses a list item by position must be tested with the root and an inheriting plateau (W-2).
- A defect reported from reading the code must be reproduced before it is fixed (T2): the reproduction changed both the scope and the cause of #123.
- The notification of a backgrounded gate script can arrive before its child process finishes; wait for the `DONE` line of its log, not for the notification.
