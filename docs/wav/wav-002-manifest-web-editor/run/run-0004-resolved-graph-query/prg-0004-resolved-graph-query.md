## Lessons Learnt

- `ElementIndex`'s own fields are `public` (`@FieldDefaults(level = AccessLevel.PUBLIC)`), but every existing command still goes through `listAllElementReferences`/`getElementByReference` rather than touching the maps directly — worth following that convention even when the fields would technically allow a shortcut, since it's what keeps "the resolution path" singular and auditable (the exact property the wave's focus line asked this run to preserve).
- When a wave manifest's `likely_paths` implies a directory structure (`cli/query/**`) that doesn't match the codebase's actual convention (flat `cli/`), the right call is to follow the codebase, name the deviation explicitly in the TDD (`DEC-1`) and the final report, and check whether the wave's own stated reason for `likely_paths` (same-batch path-overlap bookkeeping) even applies — here it didn't, since wave 002 is fully serial by its own Risks section.
