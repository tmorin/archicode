## Lessons Learnt

- A criterion of a gate that counts or compares (a `grep` that must print 0) has to be run on the starting repository before the wave: one here could not hold without changing program messages.
- Two checks written by two runs can contradict each other on one line (a voice test and a byte-for-byte test of the same list): the second run runs the first's tests before it writes its own.
- Playwright starts the jar with the `java` of the shell: JAVA_HOME of JDK 25 or every test that starts `editor serve` fails with a class file version error.
- A check that compares the page to `HEAD` cannot pass with uncommitted editor sources: commit them first.
