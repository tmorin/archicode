## Lessons Learnt

- `Parent.withElements` is abstract: a later run that adds a kind of parent must implement it (compile error otherwise) (run 0074).
- A message that must name everything a facet removed has to be made by the kernel, which is the only one that knows it: the page cannot guess what an action removes (run 0074).

- Key a cache on `modelVersion` and ask it before building the kernel input; `modelsKey(comparison, facet)` is the shared part and `modelsAreThoseOf` is the net if a replacement forgets `modelsChanged()`. A freshness test compares the cached drawing with the drawing of a page with no cache (`diagramCache = null`, `treeQuietCache = null`) (run 0073).

- The editor reads manifests through the table `READ_SCHEMA` in `standalone.html`, which `EditorReadSchemaTest` checks against the real classes: adding `plateau` to the header of every kind, or the `Plateau` kind (W-3), means editing the table and the matching Java class together (run 0072).

- Jackson 2.18+ exposes `YAMLParser.getEvent()` as the supported hook to expand aliases; the save's mark character must not be `\u0001` because `markKeyColumnLists` refuses a text that contains it (run 0071).
- A new class in `io.morin.archicode.manifest` must be added to `META-INF/native-image/.../reflect-config.json`: `NativeReflectionConfigTest` fails the first `verify` otherwise (run 0071).
