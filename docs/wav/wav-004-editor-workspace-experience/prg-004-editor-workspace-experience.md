## Findings

- `embed.sh` writes the wasm into `standalone.html` as well as into `src/main/wasm/`, so a Rust change touches the editor file.
- The shell already supports resizable right and bottom panels; no perspective uses them yet.
- On the Map a click on a box selects without changing perspective (`goto-element` does not call `setPerspective`).
- CLI order (from W-6): PlantumlViewRenderer collects style entries in a HashSet, so two styled stereotypes on one box give an undefined winner in the CLI; the editor is deterministic (later stereotype overrides earlier, property by property; by-tags over by-qualifiers). Candidate for a later run (W-6 TDD DEF-3), not in this wave.
- A human look at the real page in Chromium, light and dark, with the user's workspace, and a comparison with the CLI's PlantUML is still recommended (W-6 TDD DEF-1); also the Map chips against the ⋯ popup (W-2 DEF-3). Neither is a completion criterion.
- Process hazard (from W-6): never run mutation-checking agents that restore a file copy over standalone.html while another agent edits it.
- A container query adds no specificity: it must follow the base rules it overrides (header.test.js pins the order). W-7 should reuse .center-panel (container named center) and stereotypeBadgesHtml / styledStereotypesOf (badge CSS .stereotype-badge with --st-fill, --st-stroke, --st-text).
- Anything on the Map that depends on the selection must also be cleared by hand in showDiagramScene when it drops the selection (from W-7); W-8's link selection needs the same. renderInspectionHtml / inspectionRecordFor(sel) are the single gate of the panel (from W-7).
- Any new reader of the selection in a diagram perspective must use elementSelection() (W-8 TDD DEC-7 lists the 25 read sites). Anything else on the Map depending on a link selection must be cleared in reconcileLinkSelection (from W-8).
- Tab cost (W-8 RISK-1): links are drawn before the boxes, so Tab visits every link first on a dense map; a roving scheme could replace it without touching the selection. Deferred in the W-8 TDD: navigate to the declaring element of a relationship; put a link in the URL; centre on the selected link on the Map.
- Process: a reviewer reading standalone.html while it is being edited sees a half-edited file; have it read git show HEAD: or wait (from W-8).
