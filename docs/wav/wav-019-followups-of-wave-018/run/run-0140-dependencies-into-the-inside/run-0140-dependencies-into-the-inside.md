# Run 0140: dependencies-into-the-inside

Wave 019, W-4. A relationship towards the inside of a deployed application is a dependency of the node that hosts it, and the secondary links of a flow read what is inside the deployed element (#139, decision T5, confirmed by the author 2026-10-22). Mirror of #124 (run 0133, decision D7), which did the source side.

## Scope

1. `derived_dependencies` (and the Map, the overview, the detailed and the deep viewpoints, which share it): a relationship whose destination is inside a deployed application is a dependency towards the node that hosts that application. The destination must still be inside a deployed application; a relationship that ends inside the deployed application it starts from is internal and gives nothing. New helper `deployed_application_of` (the nearest deployed application that is or contains the destination); `Derived` gains `to_app`.
2. The secondary links inside one environment (`local_dependencies`, and the intra-environment loop of `deep_technology`), drawn for a flow only, read `relationships_of_deployed` (the relationships of everything inside the deployed element) and resolve the destination the same way.
3. Kernel contract stays 5 (no key, no shape; `OutRel.from` says who declares, `destination` says what it ends on). Wasm re-embedded (`embed.sh`, `--check` green).

Not in scope: the manual (listed below for W-9), GitHub issues (not closed or commented).

## Decisions

- Nested deployed applications: the nearest one wins (longest reference). Not exercised by any shipped file; kernel behaviour only, documented in the README.
- A relationship from a component to a component of the same deployed container is internal in the secondary links too. Side effect, pinned: a self loop on the box of a merged container (`accounts.profiles` replaces `shop.app.customers` and `shop.app.loyalty`; the removed relationship `loyalty -> customers` was a loop on its box) is gone from the comparison of the faceted views. It was invisible noise, a removed secondary link that only added the `.removed` style block to the file.
- The Map of the technology layer changes for no shipped file (`expected-boxes.json` unchanged): no shipped workspace has a destination inside an application deployed in an environment the source environment `uses`. The kernel test `the_map_of_the_technology_layer_takes_the_dependencies_towards_the_inside` pins the behaviour.
