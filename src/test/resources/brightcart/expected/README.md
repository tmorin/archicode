Computed by `generate.mjs` from the description (the model of the specification). `comparisons.json` says, for each of P1 to P6, whether `archicode diff` verifies the counts or only the model does.
`changes.json` is the table of changes of each comparison as the model computes it (elements and relationships whose state is not `none`).
`entries.json` says, for each view and each step of each story of `layered/shared/`, in which plateaus it can be drawn and what the command line says when it cannot.
